# TOX ASCII-art catalog — the source. Drawn for TOX; edit here, then run
#   node tools/ascii-art/build.mjs
# which normalizes it and writes WsCore.Client/src/lobby/asciiArt.json.
#
# An entry: a header line, then the picture up to the next header.
#   === id | Title | tag, tag | Category
# Ids are [a-z0-9-]{1,40} and are forever: messages refer to them. Removing an entry
# here only hides it from the picker (the build keeps it in the JSON as hidden).
# Printable ASCII only, at most 48 columns x 24 rows. Comments (#) only up here,
# before the first entry: below, # is part of the pictures (the banners are drawn with
# it).
