WsCore

Real-Time Multiplayer Game Server Core

Project Overview

WsCore serves as the foundational architecture for building high-performance, real-time multiplayer games. It leverages WebSockets for low-latency communication, utilizing C# on the server-side (`WsServer`) for game logic and efficiency, and a modern TypeScript client (`WsCore.Client`) for the game interface.

  • Server: .NET 9 C# game logic processing and state management.
  • Client: TypeScript client built with Phaser for rendering and user interaction.
  • Protocol: MemoryPack serialization with a 1-byte TypeId header followed by payload.

Server Setup & Running

1. Ensure Dependencies Are Met

Make sure you have the .NET 9 SDK installed to run the C# server project.

2. Start the Server

Navigate to the main server directory (`WsServer/WsServer`) and execute the following command: 

dotnet run

The server should start listening on the configured port (e.g., 5000 or 8080).

Access the Game Client

Launch the Web Client (Dev)

The TypeScript client runs on a Vite dev server. In a separate terminal, from WsCore.Client run: 

npm start

Then open the client at: http://localhost:5173

For detailed architectural diagrams and performance benchmarks, refer to the project's markdown files (e.g., ARCHITECTURE_IMPROVEMENTS.md and BENCHMARK_RESULTS.md).
