# TOX games portal — handbook

TOX hosts HTML5 games in its **Игры** section: every game has a page (cover, tagline,
description, screenshots, releases, leaderboards), is played inside its own chat room, and
counts plays. The game bridge is the MY.GAMES JAM `window.Jam` SDK, unchanged: a game
written for the jam portal runs here as is.

Articles (`docs("<id>")`):

- `agent` — publishing from a coding agent (these tools) or a script (the REST API).
- `web-build` — what a build must look like, how it is served.
- `sdk` — the `window.Jam` bridge: events, loading screen, mock ads.
- `sdk-leaderboards` — score boards.
